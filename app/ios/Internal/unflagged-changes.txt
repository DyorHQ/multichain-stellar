# An entry is a path of the app copy, as the check prints it (app/…), and its rule, in shell quoting, then its reason
# on the indented lines below it:
#   <path> any                        the file may change in any way (not a Swift file, nothing under app/ios/DyorHQ)
#   <path> literal "<old>" "<new>"    only lines that swap <old> for <new> differ (a Swift file's after stripping its
#                                     #if STELLAR_LITE blocks)
#   <path> keys -"<key>" +"<key>"     a String Catalog: exactly these keys removed (-) and added (+), and every other
#                                     key, and everything outside its strings, equal as JSON
# An entry never widens a path's own rule, so these can't be listed: app/ios/DyorKit/** (it never changes),
# app/ios/Internal/** (it always may), app/ios/project.yml and app/ios/DyorHQ/Info.plist (only the CFBundleVersion
# line), app/ios/.gitignore, app/ios/DyorHQ/Lite/** and an added Swift file anywhere.
